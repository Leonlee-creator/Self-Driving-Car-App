# 🧠 Self-Driving Car Simulation using OpenCV

This project simulates basic functionalities of a self-driving car using computer vision techniques in Python.

### 🎯 Features
- Lane detection using Hough Transform
- Pedestrian detection with Haar Cascades
- Stop sign detection
- Traffic light color interpretation (Red, Yellow, Green)
- Heads-up display (HUD) overlay for real-time feedback
